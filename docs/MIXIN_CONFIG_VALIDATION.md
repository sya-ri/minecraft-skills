# Mixin Configuration Validation

`minecraft-skills` provides a bounded, offline preflight for SpongePowered Mixin configuration
JSON. It validates configuration shape and reports evidence for referenced resources and classes
against optional entry paths from one supplied archive.

## Interfaces

CLI:

```sh
minecraft-skills minecraft validate-mixin-config example.mixins.json
minecraft-skills minecraft validate-mixin-config example.mixins.json \
  --archive-entries archive-entries.json \
  --archive-entries-complete true
```

`archive-entries.json` is a JSON array of logical archive paths, for example:

```json
[
  "example.refmap.json",
  "com/example/mixin/ExampleMixin.class"
]
```

Catalog:

```ts
import { validateMixinConfig } from "@minecraft-skills/catalog";

const result = validateMixinConfig({
  config: rawJsonText,
  archiveEntries: ["com/example/mixin/ExampleMixin.class"],
  archiveEntriesComplete: true,
});
```

MCP clients can call `validate_mixin_config` with the same JSON fields. MCP accepts metadata only;
it does not read local paths or accept binary archives.

`archiveEntriesComplete` defaults to `false`. When it is `true`, it means only that the supplied
list is complete for the supplied archive. It never claims that the list represents dependencies,
the complete runtime classpath, or classes and resources generated by a companion plugin. A
referenced entry which is not observed in that archive is therefore `unknown` evidence, not a
definitive loader error.

## Evidence and outcomes

The validator checks:

- bounded JSON data and the field shapes modeled by the audited core `MixinConfig`;
- the audited `VersionNumber` grammar and its `32767` component ceiling;
- signed 32-bit integer fields and source-backed Gson primitive coercions;
- package-relative mixin classes and refmap-wrapper classes;
- direct plugin, injection-point, and dynamic-selector class names;
- `parent` and `refmap` as classpath resource names, not class names;
- duplicate mixin declarations within one list or between `mixins` and a sided list;
- optional presence evidence for mapped references in supplied archive-entry metadata.

A name in both `client` and `server` is not reported as a duplicate by itself because those lists
are selected for mutually exclusive environments. A common plus sided declaration, or a repeated
entry within one list, can overlap and produces a warning.

Raw JSON text is preferred. The validator scans raw text for duplicate object keys and reports
last-value parsing as ambiguous source evidence. When a caller supplies an already-parsed object,
the original JSON key uniqueness is unknowable and the result remains indeterminate even when its
parsed fields are otherwise valid.

`valid` means that no definitive error was found in the checked configuration scope. `outcome` is
`indeterminate` when unknown evidence remains. `validationComplete` applies only to the documented
offline configuration checks; it is false for unknown or truncated diagnostics and for a supplied
archive list which is not usable as a complete list.

The validator does not inspect parent configuration contents, the active runtime Mixin version,
required-feature availability, environment selection, the wider classpath, class bytecode,
annotations, targets, selector meaning, injection behavior, mapping lookup, remapping, archive ZIP
structure, signatures, or runtime application. It does not validate access wideners or other
loader-specific project metadata.

Normalized relative resource paths are a conservative bounded offline profile. Their rejection by
this tool is not a claim that every Mixin service or launcher rejects the same resource name.

## Audited sources

Behavior was audited on 2026-08-25 against SpongePowered Mixin commit
`4053421aa10aaac6127d969028a29c94fe3054f6`, whose current compatibility levels extend through
`JAVA_21`:

- [MixinConfig.java](https://github.com/SpongePowered/Mixin/blob/4053421aa10aaac6127d969028a29c94fe3054f6/src/main/java/org/spongepowered/asm/mixin/transformer/MixinConfig.java)
- [VersionNumber.java](https://github.com/SpongePowered/Mixin/blob/4053421aa10aaac6127d969028a29c94fe3054f6/src/main/java/org/spongepowered/asm/util/VersionNumber.java)
- [Mixin build.gradle](https://github.com/SpongePowered/Mixin/blob/4053421aa10aaac6127d969028a29c94fe3054f6/build.gradle)
- [Mixin environment guide](https://github.com/SpongePowered/Mixin/wiki/Introduction-to-Mixins---The-Mixin-Environment)

The audited Mixin build compiles against Gson 2.2.4. Primitive adapter behavior was checked at
Gson commit `ca40a338de56871027f6c31b62f47f810f092bef`:

- [TypeAdapters.java](https://github.com/google/gson/blob/ca40a338de56871027f6c31b62f47f810f092bef/src/main/java/com/google/gson/internal/bind/TypeAdapters.java)
- [JsonReader.java](https://github.com/google/gson/blob/ca40a338de56871027f6c31b62f47f810f092bef/src/main/java/com/google/gson/stream/JsonReader.java)

Future core versions and launcher forks may add fields or compatibility levels. Those observations
are reported as unknown rather than treated as definitive incompatibilities.
